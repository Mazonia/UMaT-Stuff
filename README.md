## 🚀 Quick Start & Usage

### 1. Launch Main Web Portal
Open [`index.html`](index.html) in any modern web browser to access the central dashboard portal.

### 2. Run Python OOP Farm Quiz
```bash
cd OOP-Quiz
python main.py
python -m unittest test.py
```

### 3. Run Python Mathematics Suite
```bash
cd Maths-with-python
python -m unittest test_math_suite.py
```
