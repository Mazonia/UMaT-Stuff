# Contributing to UMaT-Stuff

Thank you for your interest in contributing to the **UMaT-Stuff** consolidated repository!

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

### 1. Reporting Bugs & Suggesting Features
- Open an Issue on GitHub describing the bug or proposed feature.
- Include steps to reproduce bugs and expected behavior.

### 2. Development Workflow
1. Fork the repository and clone your fork locally.
2. Create a new topic branch: `git checkout -b feature/my-new-feature`.
3. Make your changes adhering to code formatting and guidelines.
4. Run tests:
   - For Python OOP Quiz: `python -m unittest OOP-Quiz/test.py`
   - For Python Math Suite: `python -m unittest Maths-with-python/test_math_suite.py`
5. Commit your changes with clear, descriptive commit messages.
6. Push to your fork and submit a Pull Request.

## Code Guidelines
- **Python**: Follow PEP 8 guidelines, include type annotations and docstrings for public functions.
- **PHP**: Use prepared statements (PDO / MySQLi), sanitize user inputs, avoid raw SQL concatenation.
- **HTML/CSS/JS**: Use semantic HTML5 markup and modern responsive CSS flexbox/grid.
